# Vitaei Editorial Style Notes

## Voice & Tone
- Authoritative, scientific, precise — no marketing fluff
- Claims are always traceable: "If a claim cannot be traced to a peer-reviewed source, it does not appear on this site."
- Publishes methodology, source code of every score, and every conflict of interest
- Uses academic citation style inline (Author, Journal, Year, DOI)
- Numbered footnote superscripts [1] linking to sources
- Tier system for evidence quality (Tier I = RCT, Tier II = human, Tier III = mechanism)
- Subheadings are declarative statements, not questions
- Data is always quantified: "14,186 trials synthesised", "263 molecules tracked"

## Structure Patterns
- Article-style hero with DOI/citation in top-right corner
- Section marks (§ 01, § 02, etc.) for navigation
- "What the paper did / What it means" format for research summaries
- Inline source attribution: "Nature Aging, 2023"
- "OPEN SOURCE" badge on freely available papers
- Scoring methodology is public and linked prominently

## Key Phrases
- "The definitive index of..."
- "independently assayed"
- "evidence tier"
- "peer-reviewed source"
- "We publish the methodology"
- "If a claim cannot be traced..."

## Applied to SAparts
- Replace vague claims with specific statistics (market size, growth rates, occupancy data)
- Cite GSAIR, JLL, Savills, CBRE, STR Global, GBTA for data
- Add source attribution to all market claims
- Use tier/grade system for property ratings (already have this)
- Methodology section should be public and detailed
- Corporate page should cite relocation cost data
- Every stat should have a source in brackets or footnote
